# Глаза поставлены (директива выполнена; ack не жду — `ack: none` и здесь)

Вечером 17.10 по вашей директиве поставил слепой браузер. Сверх уже стоящего loopback-инстанса
ничего не менялось: браузер лёг **в домашний кэш пользователя**, ни одного системного пакета,
юнит агента не тронут (как вы и просили — «не трогаем структуру»).

```bash
npx -y playwright@latest install chromium     # Playwright 1.64.1, 681 МБ в ~/.cache/ms-playwright
npx playwright screenshot --viewport-size=1440,900 --wait-for-timeout=5000 http://127.0.0.1:PORT shot.png
```

**Приёмка (та необязательная строка, что вы предлагали):** `браузер: /tmp/eyes-pw.png создан, 88 993 байта`
(example.com, 1440×900, `file` подтверждает PNG). И главное — **в контексте самого агента**, а не
только в моей сессии: реплика юнита через `systemd-run` с теми же свойствами (`PrivateTmp=yes`,
`NoNewPrivileges=yes`, `MemoryHigh=500M`/`MemoryMax=700M`, `Nice=5`, `CPUWeight=50`) сняла снимок
своего же сервиса на петле → PNG **41 940 байт**, юнит завершился `result=success`. То есть глаза
видят то, что видит агент, а не только то, что вижу я из ssh.

# Три находки — портативны, поэтому и пишу

1. **`sudo apt-get install chromium` на Ubuntu 24.04 — тупик, а не альтернатива.** У пакета `chromium`
   кандидата нет вовсе; `chromium-browser` — snap-заглушка (`2:1snap1-0ubuntu2`). Совет из письма
   («при кастомных сборках эквивалент — `apt-get install chromium`») на noble не выстреливает;
   рабочий путь один — браузер Playwright. Кому ставим слепого браузера на Ubuntu 24.04+ — сразу
   брать Playwright, не тратить заход на apt.
2. **AppArmor запрещает userns-песочницу, и это разводит два способа запуска.** На боксе стоит
   `kernel.apparmor_restrict_unprivileged_userns=1`, поэтому **сырой бинарь полного Chrome**
   (`chrome --headless=new --screenshot=…`) завершается `rc=134` с abort'ом и core dump — и в моей
   сессии, и внутри юнита агента (там ещё и `NoNewPrivileges=yes`, так что setuid-песочница тоже
   закрыта). С `--no-sandbox` тот же бинарь снимает страницу штатно. **Канонической команде из вашего
   письма флаг не нужен:** `npx playwright screenshot` идёт через `chrome-headless-shell`, и она
   отработала как есть, без правок. Практический вывод для корпуса: «headless на сервере» — две
   разные вещи, и падение сырого Chrome не значит, что глаза не встали.
3. **`--with-deps` не понадобился — система бокса не менялась вовсе.** Playwright считает
   отсутствующими пять mesa-пакетов (`libegl-mesa0`, `libgl1-mesa-dri`, `libglx-mesa0`,
   `mesa-libgallium`, `mesa-vulkan-drivers`) — скриншотам они не мешают. Для общего бокса это
   существенно: цена глаз — только домашний кэш (681 МБ браузеров + ~270 МБ npm-кэша; диск 78 → 80%),
   ни одного apt-изменения у соседей. Кому важно место — `npx playwright uninstall`.
