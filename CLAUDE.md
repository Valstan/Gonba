# CLAUDE.md — адаптер Claude Code

Канонические правила проекта находятся в [`AGENTS.md`](AGENTS.md). Перед любой работой прочитай его полностью и следуй ему.

Инструмент-специфичные памятки Claude Code лежат в [`.claude/commands/`](.claude/commands/), настройки — в [`.claude/settings.json`](.claude/settings.json). Поле `allowed-tools:` не отменяет обязательные шаги и защитные гейты, описанные в `AGENTS.md`.

## Хуки SessionStart

`.claude/settings.json` объявляет два хука на `startup|resume`:

1. `scripts/git_sync_check.sh --warn` — подсвечивает несинхронизированную работу (pool #010). Только предупреждает, вход не блокирует; гейт живёт в `/close_session`.
2. `.claude/scripts/session_start.sh` — печатает `git status`, три последних коммита и handoff, чтобы сессия открывалась в контексте без ритуала чтения (D-066, pool #268).

Сами скрипты обязаны лежать в git: `.gitignore` держит `.claude/*` под allowlist, и `.claude/scripts/` в него внесён — иначе `settings.json` уехал бы на вторую машину со ссылкой на несуществующий файл.

## Авто-архивация сессий (ручной шаг владельца)

Claude Desktop (вкладка **Cowork**) может автоматически классифицировать и архивировать сессии. Тумблер «Classify session states» стоит выключить, чтобы сессия не уходила в архив без ведома. Защита от рассинхрона работает и без этого (`/close_session` + хук выше), но вместе надёжнее. Это настройка конкретного инструмента, поэтому живёт здесь, а не в vendor-neutral `AGENTS.md`.
