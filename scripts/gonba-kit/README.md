# gonba-kit — ярлыки удалённого управления ульем OpenCode на прод-боксе Гоньбы

Аналог испанского набора (`brain_matrica/docs/machines/es-vps-kit/`), но для бокса Гоньбы:
чат OpenCode в браузере, смена сервера ВПН, состояние, логи, консоль. Один файл логики
(`gonba.ps1`), ярлыки только передают действие — правки в одном месте.

## Состав

| Файл | Что делает |
|---|---|
| `1 — Чат OpenCode.cmd` | туннель `127.0.0.1:14974 → 49374` + одноразовая ссылка входа в браузер. Если служба выключена — поднимает её (и ВПН вместе с ней); заодно `git pull --ff-only` в клоне агента на боксе (`~/repo/Gonba`), чтобы улей не открывался на недельной давности коде |
| `2 — Сменить сервер ВПН.cmd` | `/etc/neural/egress.d/10-nextgenvpn.sh`: следующий сервер подписки до рабочего выхода, печатает «было → стало», фактический выход движка и его health. Движок **не перезапускается** |
| `3 — Перезапустить движок.cmd` | `systemctl restart opencode-web` + ожидание ответа (ремонт зависшего; ВПН не трогает) |
| `4 — Выключить улей.cmd` | гасит службу `opencode-web` **и** ВПН-клиент на боксе, плюс туннель: движок не ест память и не жжёт сетевую квоту, когда им не пользуются (mandate D-152) |
| `5 — Состояние сервера.cmd` | uptime, load, RAM, диск, юниты (`opencode-web`, `neural-vpn`, сторож, `gonba`), версия и health движка, текущий egress, туннель |
| `6 — Логи движка.cmd` | `journalctl -u opencode-web -n 40` |
| `7 — SSH-консоль.cmd` | интерактивный `ssh GONBA` (`exit` — выход) |
| `0 — Закрыть туннель.cmd` | только туннель этого компьютера; служба на боксе продолжает работать |
| `gonba.cmd` | диспетчер: без аргументов — меню; с аргументом — `chat`, `vpn`, `restart`, `off`, `stop`, `status`, `logs`, `shell`, `doctor` |
| `gonba.conf` | алиас, локальный порт туннеля, порт движка |

## Куда ставить

Папка переносится целиком на любую машину владельца:

1. Скопировать папку (например, в `D:\Desktop\GONBA\`).
2. Убедиться, что в `~/.ssh/config` есть алиас `GONBA` (адрес и ключ живут только там, D-038).
3. Проверка: `gonba.cmd doctor` или ярлык «5 — Состояние сервера».

Секретов в наборе нет: пароль движка остаётся на боксе (`~/.config/opencode-web/anon.env`),
ссылка входа одноразовая (5 минут), наружу не открыто ни одного нового порта.

## Грабли

- **Системный `ssh` 7.7p1** (Windows) даёт 11–30 с на соединение (G475) — набор сам выбирает
  `ssh` из Git for Windows и предупреждает, если лучшего нет.
- **Свой ВПН на компьютере** (Happ) может увести трафик до бокса в туннель и уронить баннерный
  обмен: лечится `/32`-маршрутом мимо ВПН (D-148).
- **Порт 14974 занят** — закрыть туннель (`0 — Закрыть туннель.cmd`) или сменить
  `CHAT_LOCAL_PORT` в `gonba.conf`.
- **`-Off` на боксе ≠ сайт**: останавливается только юнит `opencode-web`; `gonba.service`,
  Postgres и nginx не затрагиваются.
- **Клон агента обновляется только по клику «Чат»** (`git pull --ff-only`), деплой его не трогает:
  деплой тянет боевое дерево `~/GONBA`. Грязное дерево или свои коммиты в клоне останавливают
  обновление — набор скажет об этом, а не перепишет.

## Чего набор не делает

- Не перезагружает прод (простой всех сайтов) — для этого SSH-консоль, осознанно.
- Не хранит секретов и не открывает новых портов: снаружи только `22` (и `443` у сайта).
- Не управляет ВПН на твоём компьютере: здесь — только серверный egress движка.
