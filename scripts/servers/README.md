# Каталог серверов запускателя (`servers\<алиас>.conf`)

Эта папка — точка стыка между запускателем Гоньбы и **каталогом серверов Мозга**
(`docs/machines/servers/` в `brain_matrica`). Один сервер — один фрагмент `<алиас>.conf`;
фрагмент — это **валидный `opencode-web.conf` целиком**, тот же диалект:

```
SSH_TARGET=...      # алиас из ~/.ssh/config этой машины либо user@адрес
IDENTITY_FILE=...   # приватный ключ (пусто — ключи по умолчанию / ssh-agent)
LOCAL_PORT=...      # локальный порт туннеля (у разных серверов — разные)
REMOTE_PORT=...     # порт сервера OpenCode на боксе
```

Кавычки не нужны, `#` — комментарий: формат читается тем же кодом, что и обычный
`opencode-web.conf`, поэтому «второй формы» не заводится.

## Как этим пользоваться

```powershell
powershell -ExecutionPolicy Bypass -File scripts\opencode-web.ps1 -Servers          # что лежит рядом
powershell -ExecutionPolicy Bypass -File scripts\opencode-web.ps1 -Server <алиас>   # подключиться к серверу
```

```bash
./opencode-web.sh --servers          # то же на Linux/macOS/Git Bash
./opencode-web.sh --server <алиас>
```

Остальные ключи не меняются: `-Setup` / `-Check` / `-Stop` / `-Off` работают и с `-Server`,
и без него. `-Check` печатает, каким сервером пульт готов ходить; `-Server <алиас> -Setup`
заводит фрагмент на месте, если сервер добавляется не Мозгом.

**Названный сервер не подменяется молча.** Если фрагмента нет, запускатель останавливается
и перечисляет, что лежит рядом. Так задумано: «нет файла — работай как раньше» означало бы,
что опечатка в имени (`-Server es-vps` вместо `-Server es_vps`) уводит владельца на **другой
бокс** без единого слова. Это единственное отступление от исходного предложения Мозга
(письмо от 18.10.2026, «Формат пульта»), и оно согласовано.

## Чего здесь не лежит и почему

Фрагментов в git **нет** — только этот README. Внутри фрагмента адрес бокса, порт и имя
ключа; репозиторий публичный, а такие значения в отслеживаемые файлы не кладём вообще
(правило D-038). Поэтому:

- `scripts/servers/*.conf` — в `.gitignore`;
- фрагменты раскладывает на машине владельца Мозг (каталог серверов), там же у них статус
  «готов / ждём доступ»;
- приватные ключи между машинами владельца переносит тоже Мозг; запускатель о ключах ничего
  не знает — он идёт по уже подготовленной раскладке (`IDENTITY_FILE` / алиас).

Проверить раскладку после доставки: `-Server <алиас> -Check` — он покажет и фрагмент,
и ssh-цель, и состояние службы на боксе.
