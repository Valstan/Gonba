# Project worlds UX

**Статус:** implementation in progress, 2026-08-04.

## Цель

Сократить пользовательскую навигацию до 2–3 уровней, дать быстрый переход между проектами и сделать каждый проект визуально самостоятельным без форка функциональности.

## Инварианты

- Главная → проект → раздел; более глубокая цепочка не требуется.
- Все существующие публичные URL сохраняются.
- Реальные изображения проекта приоритетнее generated art.
- Motion отключаем или упрощаем при `prefers-reduced-motion`.
- Generated assets не содержат текста, логотипов и людей; UI-текст остаётся доступным HTML.
