## Failed approaches (этой нитки)

- **`npm audit fix --omit=dev`** — флаг не только фильтрует отчёт, он **подрезает дерево**: снёс devDependencies вместе с TypeScript, и следующий `tsc` упал с «No such file or directory», выглядя как поломка обновления. Для чтения — `npm audit --omit=dev`, для починки — `npm audit fix` **без** флага.
- **Греп по `src/` как приёмка правки контента** — после фикса slug'а греп дал ноль и выглядел доказательством; а меню живёт в глобале `header` в БД, и 404 остался на каждой странице. Для всего, что редактируется через admin, приёмка — **запрос к проду**, не греп по репозиторию.
- **Грепать версию Payload в standalone-бандле** — её там нет ни строкой: пакет вкомпилирован в чанки Next. Версию снимать с дерева на боксе.
- **Принимать грабли из письма без проверки** — предупреждение про `next-env.d.ts` обещало красный `tsc` в CI; у нас его нет (`skipLibCheck: true` + `.next/types/**/*.ts` уже в `include`). Дописывание строки реально, краснота — нет.
- **Текст с обратными кавычками внутри `python -c "…"` и heredoc** — bash выполнил их как подстановку и покрошил вставку в backlog. Нарушил D-046 **дважды за сессию**; оба раза лечилось переписыванием скрипта файлом.
- **Монитор деплоя по ожидаемому SHA** — squash-merge даёт на `main` другой SHA, цикл молча докручивает вхолостую. Сверять по `status=completed` и времени.
- **Короткий якорь при правке `PENDING_FOLLOWUPS.md`** — метка `_(aging: added 2026-09-18 …)_` встречается **шесть** раз; предохранитель в скрипте отказался править и был прав. Якорь брать вместе с текстом пункта.
