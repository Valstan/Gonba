SQL — файлом, не через `psql -c` (D-046):

```bash
scp q.sql GONBA:/tmp/q.sql
ssh GONBA 'set -a; . /etc/gonba/gonba.env; set +a; psql "$DATABASE_URL" -f /tmp/q.sql'
```

⚠️ **Время в базе — UTC.** PostgreSQL на боксе сидит на `Etc/UTC`, ОС на `Europe/Moscow`. Сравнивать `last_sync_at` с временем systemd напрямую нельзя — на этом я сегодня уже ошибся (см. Failed approaches).

Смотреть три вещи:

1. **Доля `fallback` упала?** Была 47 % (8 из 17 с 25.08). Обрезание по бюджету теперь имеет **отдельную** причину в `rationale` — если оно вернётся, это будет видно сразу и не спутается с молчанием.
2. **Вердикты по существу:** записи из общей группы села (`218688001`) должны перестать оседать на `gonba`.
3. **Доля попаданий в префиксный кэш** — пишется в `vk_classification.usage`, считается обычным SQL.

Дальше по порядку, не перепрыгивать: приёмка → расхождения править **текстом правил в админке**, не кодом → и только потом запрет, с одного источника и первым шагом без запрета.
