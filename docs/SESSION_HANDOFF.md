## Failed approaches (этой нитки)

- **`sudo apt-get install chromium` на Ubuntu 24.04** — у пакета `chromium` нет кандидата, `chromium-browser` — snap-заглушка (snapd в контейнере не работает). Не повторять: рабочий путь только `npx playwright install chromium` (user-local).
- **`--with-deps` у Playwright** — тянул бы 6 пакетов mesa и менял системный слой общего бокса; снимки работают без них. Отклонено осознанно: прод-бокс чужой контур, система не трогается.
- **Сырой `chrome --headless=new` внутри юнита** — падает `rc=134` (AppArmor: `kernel.apparmor_restrict_unprivileged_userns=1` запрещает userns-песочницу). Не повторять без `--no-sandbox`; канонический `npx playwright screenshot` идёт через `chrome-headless-shell` и работает как есть.
- **`-Check` как доказательство работоспособности ярлыка** — зелёный `-Check` скрывал падение двойного клика (в неинтерактивной среде ssh дописывает в stderr предупреждение, и файл не пустой). Теперь доказательство — регрессия с реально пустым stderr + живой прогон.
