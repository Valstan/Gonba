## Текущая нитка

**Нить, которую тянула прошлая сессия, закрыта: поломка деплоя оказалась не «грязным локом», а шагом, который этот лок пачкает сам.**

`npm install` в шаге `Refresh box node_modules if lockfile changed` переписывал `web/package-lock.json` на боксе — 63 удалённые аннотации `"libc"` у optional-зависимостей, — и **следующий** `git pull --ff-only` отказывался работать. Прогон `36695574270` падал на этом дважды; механизм был догадкой, стало фактом.

Правка ([PR #244](https://github.com/Valstan/Gonba/pull/244), `dec08d4`): `npm install` → `npm ci` (не пишет лок по контракту, ставит дерево по локу, расхождение с `package.json` считает ошибкой — бокс получает то же дерево, что собирает CI). Плюс **гейт на состояние** после установки и **шаг-предупреждение перед `pull`**: не фейл, потому что грязный файл, которого не касается incoming-коммит, pull не блокирует.

**Сброс лока — с подтверждением владельца, 30.09.** Перед сбросом дифф перепроверен тем же предохранителем (63 удаления, 0 добавлений, посторонних нет), `git checkout --`, после — настоящий предикат: `git pull --ff-only` → `Already up to date`.

## Failed approaches (этой сессии)

- **Скрипт проверки диффа посчитал 64 строки вместо 63** — вместе с заголовком `---` diff'а, и выдал «в диффе посторонние изменения». Остановил бы правильный сброс на пустом месте. Правильно: считать то, что удалено, а не всё, что начинается с `-`. Тот же класс, что был с 63 строками «без заголовка» в первой версии.
- **Кириллица в `.ps1`** — PowerShell 5.1 читает файл без BOM как ANSI, и скрипт падает на парсере. Поймано трижды за сессию. Все `.ps1` писать ASCII-only.
- **`grep -oE '^[A-Z_]+(?==)'`** — lookahead без `-P` не работает, grep молчал, и вывод читался как «переменных нет». Правильно: `sed -n 's/^\([A-Z_][A-Z0-9_]*\)=.*/\1/p'`.
- **PowerShell грызёт `|` в jq-аргументе `gh`** (`unknown command "|"`) и не поддерживает `<` для редиректа — длинные команды писать скриптом файлом.
- **Имя файла ADR-0012 угадано неверно** (`0012-karman-passport-identity.md`); реальное — `0012-ecosystem-passport.md`. Ссылки на brain проверять `Test-Path` до коммита.
- **Откатил `web/next-env.d.ts`** — Next.js перегенерировал его при локальном `lint`, добавив ссылку на `./.next/types/routes.d.ts`, которого нет в чистом checkout. Это ровно ловушка G344; правка не моя и в коммит не пошла.
- **`\$(...)` внутри двойных кавычек в PowerShell — не экранирование, а локальная подстановка.** Проверяя HEAD на боксе, я написал `ssh GONBA "… \$(git rev-parse --short HEAD) …"` и PowerShell выполнил `$(...)` **на своей машине**: в логе оказался коммит моей локальной ветки, которого на боксе нет. Я на этом поднял ложную тревогу («бокс не на main»). Спас случайный перепровер через скрипт-файл, где `$` не разбирается PowerShell. **Правило: `$` в команде, уходящей на удалённый хост, — либо одинарные кавычки снаружи, либо скрипт файлом.** Тот же класс, что и три предыдущие грабли: слой переноса молча даёт правдоподобный неверный ответ.
- **API `actions/runs/<id>/jobs` вернул 3 шага из 20** — список шагов приходит усечённым. Не строить приёмку на нём; брать вывод лога или вывод самого шага.
