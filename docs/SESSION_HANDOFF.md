## Следующий шаг

**Копить вердикты, не принимать решений на N=2.** Ориентир — 8–10 записей из общей группы села (`sourceProjectSlug = 'gonba'`), каждую сверять с разметкой владельца. Расхождения править **текстом правил в админке**. Запрет — только после этого, с одного источника, первым шагом без запрета.

Проверить первой новой классификацией, что `usage` теперь пишется:

```sql
SELECT id, vk_classification->'usage' FROM posts
WHERE vk_classification IS NOT NULL ORDER BY id DESC LIMIT 3;
```

SQL — файлом через `scp` + `psql -f` (D-046). **Время в базе — UTC**, `created_at AT TIME ZONE 'Europe/Moscow'` для сверки с расписанием. `usedFallback` в JSON нет — fallback отличается по `provider = 'fallback'`.

Отдельный маленький PR, когда будет окно: **GraphQL-коллизия типов `Message`** (коллекция `messages` × блок `message` form-builder'а) — эндпойнт `/api/graphql` отдаёт 500 с 28.08. Диагноз и два варианта лечения — в backlog.

## Failed approaches (этой нитки)

- **`grep -r` по `sites-enabled/`** — молчит, потому что там симлинки; нужен `-R` или `nginx -T`. Полчаса на «записи нет» при том, что она была.
- **Приёмка nginx в ту же секунду, что `reload`** — запрос ушёл в старый воркер и показал ответ дефолтного блока; `nginx -t` и `-T` при этом были правы. Приёмку после `reload` снимать следующим шагом и не одним запросом.
- **Сравнивать файл на диске Windows с телом с прода по md5** — CRLF в рабочей копии; сравнивать с `git show HEAD:`.
- **`usedFallback` в SQL по JSON** — ключа в базе нет, только в TypeScript-типе; фильтр по нему давал «0 и 0» и выглядел как «всё сломано». Смотреть, какие ключи реально лежат (`jsonb_object_keys`), прежде чем фильтровать по типу.
- **Имя CI-воркфлоу «по памяти»** (`web-quality.yml`) — файла нет, есть `CI`; run искать по SHA коммита, не по имени.
- **Первое измерение с `-w %{redirect_url}` внутри того же ssh, что и `reload`** — см. вторую строку; выделено отдельно, потому что соблазн «повторить ту же команду» силён.

## Не забыть (low-priority)

- **`ack: none` у мандата = нет гейта приземления.** Предложено brain как класс.
- **`shell: bash` не объявлен ни в одном шаге `.github/workflows`** — сплошного прохода не было.
- **`last_error` не чистится при успехе** — теперь виден на двух источниках (id 6 и 7).
- **Авто-мерж в репозитории выключен** (`enablePullRequestAutoMerge`) — `gh pr merge --auto` отказывает; мержить по зелёному CI руками, деплой — по одному.
- **npm на Windows берёт cmd.exe** — `pnpm run typecheck` падает на `NODE_OPTIONS`; звать `./node_modules/.bin/tsc --noEmit` из git-bash.
- **Два int-теста на Windows не грузятся локально, в CI зелёные** — не принимать за регрессию.
- **Сетевой путь до GitHub отсюда деградирован** — `git push`/`gh api` иногда падают по таймауту с первого раза; повторять, не диагностировать.
