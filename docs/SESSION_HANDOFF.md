## Failed approaches (этой нитки)

- **Пересобирать снапшот через `payload migrate:create`** — не годится: он пишет `.json` только
  вместе с диффом, а дифф идёт против устаревшего снапшота (та самая мина G192) и уходит в
  интерактивные вопросы «enum создан или переименован?» — в headless висяк. **Правильно** — прямой
  `generateDrizzleJson(adapter.schema)` (`scripts/write-schema-snapshot.ts`), только `.json`, без диффа.
- **`NEXT_PUBLIC_*` для конфига аналитики** — отклонено: с переездом сборки в CI (2026-06-11)
  NEXT_PUBLIC запекается в бандл из GH-secret, «выключаемо без деплоя» не выполняется. **Правильно** —
  force-dynamic роут, читающий runtime-env бокса.
- **Считать 15 `SET DEFAULT` из probe дрейфом** — ложный след: те же стейтменты эмитятся против
  dev-БД, которую push держит ≡ конфигу; `information_schema` показывает, что дефолты стоят.
  Это шум drizzle-kit → отфильтрован в скрипте, на exit code не влияет.
